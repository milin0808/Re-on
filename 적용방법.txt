RE:ON Memory Engine - 승환님 음악 조회 응답 호환 패치
================================================

이 파일은 전체 프로젝트가 아닙니다. 기존 Re-on/memory-engine 코드에 덮어쓸
변경 파일만 들어 있습니다.

[1] 현재 Git 브랜치 확인
    cd C:\Users\milan\reon\Re-on
    git switch minjoung
    git status

[2] 기존 memory-engine 폴더가 있는 Re-on 프로젝트 루트에서,
    ZIP 파일을 압축 해제합니다. ZIP 안의 'memory-engine' 폴더를
    기존 'memory-engine' 폴더와 병합하고 동일 파일은 덮어쓰기 합니다.

    PowerShell 명령(다운로드 폴더에 ZIP을 저장한 경우):
    Expand-Archive -Path "$HOME\Downloads\REON_Memory_Engine_CoreAdapter_PATCH.zip" -DestinationPath "." -Force

    압축 안의 이 안내 파일도 프로젝트 최상단에 들어갑니다.
    원하지 않으면 삭제해도 됩니다.

[3] 테스트
    cd memory-engine
    .\run_tests.bat
    .\run_server.bat

    웹 브라우저에서 http://127.0.0.1:8000/docs 접속 후
    POST /api/v1/memories/analyze/core 를 선택하고
    examples/core_request.json 의 전체 내용을 넣어 테스트합니다.

[4] GitHub 기존 PR에 수정 반영
    cd ..
    git add memory-engine/
    git commit -m "feat: add Spring Boot music response adapter"
    git push upstream minjoung

    PR이 아직 Merge 전이면 기존 PR #1에 수정사항이 자동 반영됩니다.

[주의]
  - 현재 승환님 브랜치에 구현된 것은 음악 메타데이터 조회 API뿐입니다.
    Moment CRUD/DB가 완성된 것은 아닙니다.
  - Core Moment 입력 예시는 추후 통합을 위한 제안 구조입니다.
  - channelTitle을 곧바로 artist로 사용하지 않습니다.
    정확한 artist가 없고 채널명이 '아티스트 - Topic' 형태가 아니면
    API가 422를 반환하도록 안전하게 처리했습니다.
  - 기존 분석 API 경로(/api/v1/memories/analyze)는 그대로 유지됩니다.
